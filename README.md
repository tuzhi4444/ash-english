# Ash英语 · 听说一体训练

面向「能读能写、但听不懂说不出」的学习者。用 **听音 → 建反射 → 框架输出** 代替背单词扣语法。

**在线使用：** https://tuzhi4444.github.io/ash-english/

打开即用，无需注册。学习进度存在浏览器本地（localStorage），不上传任何数据。

---

## 怎么练

每天一关，四项任务做满才算过关，做不完不解锁下一关。**不限天数**——进度由掌握程度决定，练到词库通关为止。

| 模块 | 练什么 |
|---|---|
| 📚 单词学习 | 翻卡 / 听写 / 语境填空 / 听辨，四种模式，艾宾浩斯间隔复习 |
| 🏗️ 框架造句 | 给句型模板 + 中文提示，填入正确词形；答错走三级渐进提示 |
| 🎤 Shadowing | 播放原声 → 跟读 → 语音识别校验，给出词级匹配率 |
| 👂 听辨训练 | 单句听辨 + 连续听力（听整段短文再答理解题），可导入自己的材料 |

### 三个阶段

阶段由**能力**推进，不看天数：

- **Phase 1 冷启动** — 建立声音-画面反射
- **Phase 2 阻抗突围** — 巩固 300 词且巩固率 ≥60% 解锁
- **Phase 3 肌内固化** — 巩固 700 词且巩固率 ≥70% 解锁
- **维持模式** — 词库发完后自动进入

每天约 1 小时（Phase 1 约 46 分，Phase 3 约 58 分）。嫌重可在设置里调低「每日新词量」。

## 内容

- **1902 个词** — 含口语词频排名（SUBTLEX）、动词变形、场景标签、例句中英对照
- **150 篇短文 / 354 道理解题** — 三阶段分级，覆盖起居、职场、就医、租房、旅行、人际等日常场景
- **36 个句式框架** — 三阶段各 12 个，含疑问句、祈使句、虚拟语气、倒装

### 词库是按口语高频重建的

原始词表虽自称「中小学1500词」，实测缺 `do`(口语第26高频) / `why` / `happy` / `would` / `eat` / `work` 等最基础的词，却收了 `sander`(砂磨机) / `knoll`(小丘) / `fauld` 这类口语两万名开外的词，还有三个拼写错误的假词。学完也到不了「听懂日常对话」。

现已按 SUBTLEX 口语词频重建，新词按词频从高到低投放——**第 1 关学的就是 `you the to it that and do`**：

| 口语高频覆盖 | 重建前（1423词） | 现在（1902词） |
|---|---|---|
| 前 500 词 | 86% | **99%** |
| 前 1000 词 | 76% | **99%** |
| 前 2000 词 | 64% | **98%** |
| 前 3000 词 | 56% | **97%** |
| 3000 名开外的无用词 | 448 个 | **1 个** |

研究界认为高频 3000 词覆盖日常口语约 95%——现在的词库基本达到了这个量级。

筛词不只看词频：SUBTLEX 是影视字幕语料，`gun` / `murder` / `colonel` 在电影里高频、日常对话里用不到，已剔除；人名、语气词、脏话同理。反过来 `panda` / `blackboard` 口语罕见但属课本必学，予以保留。

内置短文约够练一个月不重复。之后可在「听辨训练 → 连续听力 → 导入材料」里粘贴任意英文（新闻、歌词、台词），自动断句、朗读、出题，素材无限。

## 技术

React 19 + TypeScript + Vite，纯前端，无后端、无账号、无第三方运行时依赖。

- **发音**：Web Speech API（`speechSynthesis`），自动优选高质量语音
- **语音识别**：`SpeechRecognition`，不支持的浏览器自动降级为纯跟读模式
- **存储**：localStorage + 自动备份，支持导出/导入进度 JSON

### 本地开发

```bash
npm install
npm run dev      # 开发服务器
npm run lint     # oxlint
npx tsc -b       # 类型检查（注意用 -b，根 tsconfig 是 references 结构）
npm run build    # 构建
```

构建产物是 **`dist/Ash英语.html`** —— 一个自包含的单文件（约 960KB），**双击即可离线使用**，拷到 U 盘、发给别人都行，不需要终端和网络。

> ⚠️ 项目根目录的 `index.html` 是 Vite 的开发入口，不是给人打开的（双击它会看到提示页）。

### 浏览器要求

Chrome / Edge / Safari 均可。语音识别在 Chrome / Edge 上最稳；不支持时 Shadowing 会自动降级为「听原声 → 跟读 → 自评」。

## 数据

学习进度只存在你自己的浏览器里，换设备或清缓存会丢失。设置页提供**导出进度**（下载 JSON）和**导入进度**，换设备时用它迁移。

注意：**在线版和本地双击版的进度不互通**（浏览器按来源隔离存储），用导出/导入搬运。
